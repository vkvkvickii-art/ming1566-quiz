# 《测测你是〈大明王朝1566〉里的谁》趣味人格测试网页

无需后端与第三方依赖，支持电脑与手机自适应运行，开箱即用。

## 目录结构

- `index.html`：标准模块化入口页面（双击即可在浏览器运行，或直接部署至静态服务器 / GitHub Pages / Vercel）
- `css/style.css`：明代刻本乌丝栏与宣纸朱砂国风样式表（含移动端与纯净截图模式适配）
- `js/data.js`：30道现代生活/职场情境单选题库、六大心性维度定义与12位核心人物完整判词档案
- `js/app.js`：六维白化向量评分引擎、答题状态自动保存/回退、纯 SVG 雷达图与原生 Canvas 高清分享海报生成器
- `测测你是大明王朝1566里的谁_单文件版.html`：将 HTML + CSS + JS 合并为一体的独立单文件版，方便直接发给微信/飞书好友双击打开体验

## 核心特性

1. **零门槛情境题**：30道单选题分为六卷（日常起居、职场风波、人情往来、进退取舍、逆境承压、底线心境），不考剧情与历史知识。
2. **均衡精准的六维算法**：从「执道、驭局、藏锋、任事、温情、风骨」六个维度建模，经 10 万次蒙特卡洛模拟校准，12 位人物（嘉靖帝、海瑞、胡宗宪、张居正、严嵩、吕芳、杨金水、赵贞吉、沈一石、高翰文、王用汲、芸娘）触发概率均稳定在 `8.0% ~ 8.7%` 之间，且典型人格画像 100% 精准命中。
3. **专为小红书 / 朋友圈分享优化**：
   - 支持一键生成高清 PNG 宣纸判词海报（电脑自动下载，手机端支持长按保存）
   - 支持「纯净截图模式」（隐藏所有按钮，方便手机直接一屏/长截图）
   - 支持一键复制带排版的小红书/朋友圈分享文案
